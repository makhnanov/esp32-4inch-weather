# Погода на ESP32 + 4" тачскрин

*[English version](README.en.md)*

Слева — погода сейчас, справа — прогноз на завтра. Сверху табы городов:
**Алматы** (по умолчанию), Омск, Томск, Астана, Питер.

В каждой половине: температура крупными цифрами слева от иконки явления, под
ней — влажность и давление жирными числами (чтобы читались издалека), ниже
осадки и мин/макс.

```
 Алматы | Омск | Томск | Астана | Питер
-----------------------------------------
  СЕЙЧАС              |  ЗАВТРА
   13° [иконка]       |   18° [иконка]
  В основном ясно     |  Пасмурно
  ------------------  |  ------------------
   61%      700 мм    |   56%      698 мм
  Влажность Давление  |  Влажность Давление
  Осадки      0.0 мм  |  Осадки         0%
  Мин/макс   9°/20°   |  Ночью           9°
-----------------------------------------
 Онлайн                     обновлено 13:45
```

Давление — **локальное** (`surface_pressure`), в мм рт.ст., как на местных
погодных сайтах. Для Алматы на высоте 785 м это ~700 мм, а не ~760: приведённое
к уровню моря (`pressure_msl`) читалось бы на 70 мм выше и расходилось бы с
барометром в комнате.

Данные берутся с [Open-Meteo](https://open-meteo.com/) — без API-ключа и без
регистрации. Время наблюдения показывается в часовом поясе самого города
(`timezone=auto`), так что NTP на плате не нужен.

## Железо

ESP32-WROOM-32E (ESP32-D0WD-V3, 4 МБ флеш), CH340 на USB, панель 480x320.

Распиновка **определена перебором на живой плате**, а не взята из даташита —
и она отличается от того, что обещал продавец: ёмкостного GT911 на плате нет
(ни одного устройства на I2C), зато есть **резистивный XPT2046**, сидящий на
той же шине SPI, что и дисплей.

| Узел | Сигнал | GPIO |
|---|---|---|
| ST7796 (дисплей, SPI2) | SCLK / MOSI / MISO | 14 / 13 / 12 |
| | CS / DC / RST | 15 / 2 / — |
| | подсветка (PWM) | 27 |
| XPT2046 (тач, та же шина) | CS | 33 |
| | IRQ | не используется |

Пара замечаний, которые стоили отладки:

* **Панель инвертирована** (`cfg.invert = true`) — без этого цвета негативом.
* **IRQ тача намеренно не подключён в конфиге** (`pin_int = -1`). LovyanGFX
  считает высокий уровень на этой линии за «не нажато», поэтому неверно
  угаданный пин тихо убивает касание целиком. Опрос по SPI работает всегда.
* **Open-Meteo отвечает `Transfer-Encoding: chunked`** без `Content-Length`.
  `http.getStream()` отдаёт ArduinoJson сырые куски с их длинами и парсинг
  падает с `InvalidInput` — поэтому тело читается через `http.getString()`.
* **Символов `°` и `…` нет ни в одном из кириллических шрифтов** — это нашла
  `make check` по таблицам глифов, причём `…` уже успел попасть в четыре строки
  и рисовался пустым местом. Градус рисуется кружком, многоточие — три точки.
* **Крупные числа набраны шрифтами `fub*_tn`** (FreeUniversal Bold, только
  цифры): жирной кириллицы крупнее 13 px в U8g2 нет, поэтому числа идут жирным
  шрифтом, а подписи к ним — обычным.

## Wi-Fi

Логин и пароль лежат в `.env` и больше нигде:

```
Wifi=ИмяСети
Password=пароль
```

`tools/gen_secrets.py` превращает это в `esp32-weather/secrets.h` при каждой
сборке. Оба файла в `.gitignore`, формат показан в `.env.example`. Учти, что
собранный бинарник содержит креды открытым текстом — поэтому `build/` тоже
игнорируется.

## Сборка и прошивка

```sh
cp .env.example .env   # и вписать свою сеть
make deps     # один раз: ядро esp32 + LovyanGFX + ArduinoJson
make check    # проверки без железа (см. ниже)
make flash    # собрать и залить
make monitor  # смотреть лог
```

### `make check`

Две проверки, которые не требуют платы и ловят то, что иначе видно только
глазами на экране:

* **глифы** — каждая строка проверяется тем шрифтом, которым реально
  рисуется (цифровые `fub` не спрашивают кириллицу). Так нашлись `°` и `…`.
* **раскладка** — ширина текста считается по тем же метрикам u8g2, что и на
  устройстве, и проверяется, что на худших значениях ничего не наезжает:
  температура не лезет на иконку, колонки влажности и давления не сходятся,
  описания и подписи табов не обрезаются.

Константы геометрии в `tools/layoutcheck.c` дублируют `esp32-weather/ui.h` руками — включить
настоящий заголовок нельзя, он тянет LovyanGFX и ядро Arduino. После правки
раскладки прогонять `make check` заново.

## Касание

У резистивной панели нет фиксированной привязки координат, поэтому при первом
запуске прошивка просит нажать на стрелку в каждом из 4 углов. Результат
сохраняется в NVS и переживает перепрошивку (NVS лежит в отдельном разделе).

**Перекалибровать:** держать палец на экране в момент включения.

### Известное ограничение

Калибровка блокирует загрузку. Если когда-нибудь стереть NVS при неисправном
тачскрине, плата будет ждать на ней вечно вместо показа погоды. Лечится
таймаутом — не реализовано.

## Что где лежит

Скетч лежит в подпапке `esp32-weather/`, потому что arduino-cli требует, чтобы
имя папки совпадало с именем `.ino` внутри. Благодаря этому репозиторий можно
называть и клонировать как угодно — сборка не ломается.

| Файл | Зачем |
|---|---|
| `esp32-weather/esp32-weather.ino` | setup/loop, табы, калибровка, цикл обновления |
| `esp32-weather/config.h` | пины, список городов, тайминги |
| `esp32-weather/display.h` | описание панели и тача для LovyanGFX |
| `esp32-weather/weather.h` | запрос к Open-Meteo и разбор ответа |
| `esp32-weather/ui.h` | раскладка экрана и отрисовка |
| `esp32-weather/icons.h` | коды WMO → текст и векторные иконки |
| `esp32-weather/theme.h` | палитра |
| `esp32-weather/fonts_ru.c/h` | кириллические и жирные цифровые шрифты из U8g2 |
| `tools/gen_secrets.py` | `.env` → `esp32-weather/secrets.h` |
| `tools/glyphcheck.c` | есть ли глифы для всех строк |
| `tools/layoutcheck.c` | влезает ли текст, не наезжает ли |

### Добавить город

Одна строка в `CITIES[]` в `esp32-weather/config.h` (имя, широта, долгота) — табы
раскладываются по ширине автоматически. При пяти табах по 96 px надписи
влезают с запасом; для более длинных названий имеет смысл сократить подпись.

### Как обновляются данные

Данные считаются свежими 10 минут. Открытый город обновляется первым, остальные
догружаются по кругу в фоне — поэтому переключение таба показывает цифры сразу,
а не спиннер. Неудачный запрос не стирает уже показанные значения и
повторяется не чаще раза в 30 секунд.
